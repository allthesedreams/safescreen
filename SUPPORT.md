# SafeScreen support

## Before reporting a problem

Confirm that you are running the latest release, then use **Restore area now**
from the tray menu. If the problem remains, collect:

- SafeScreen version;
- Windows version;
- display resolution and scaling;
- taskbar position and auto-hide state;
- saved left, top, and bottom margins;
- the exact action that caused the layout to reset.

Use the [bug report form](https://github.com/allthesedreams/safescreen/issues/new?template=01-bug.yml).
Redact personal content from screenshots before attaching them.

SafeScreen cannot repair an LCD panel or recover pixels that are physically
damaged. It only keeps Windows content away from selected edges.
