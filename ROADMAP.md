# Roadmap

SafeScreen is intentionally small. These are candidate directions, not release
promises.

## Next candidates

- Multi-monitor selection and per-display profiles.
- Optional right-edge exclusion.
- Signed installer and simpler in-app updates.
- Import and export of named screen profiles.
- Better diagnostics for unusual taskbar and scaling configurations.

Feature requests should explain the damaged-screen setup, expected behavior,
and the smallest useful change. Use the
[feature request form](https://github.com/allthesedreams/safescreen/issues/new?template=02-feature.yml).
