# Changelog

All notable SafeScreen changes are documented here.

## 1.4.1 — 2026-09-10

- Added a visible **Start with Windows** toggle to the tray menu.
- Kept autostart scoped to the current Windows user.
- Preserved the last selected margins across sessions.

## 1.4.0 — 2026-09-10

- Added the full-screen visual area picker.
- Added tray profiles, enable/disable controls, and layout recovery.
- Added branded iconography and the compact visual fallback editor.
- Published the first standalone Windows release.
