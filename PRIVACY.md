# Privacy

SafeScreen is designed to run entirely on the local Windows computer.

- No telemetry is collected.
- No analytics SDK is included.
- No network request is made.
- No account or sign-in is required.
- No screenshots or screen contents are recorded.
- Settings stay in the current user's Windows registry.

The repository and release package intentionally exclude development logs,
backups, screenshots, machine-specific paths, and user data.
