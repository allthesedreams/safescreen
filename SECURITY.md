# Security policy

## Supported version

Security fixes target the latest published release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose local files,
execute unintended commands, or weaken Windows account boundaries. Use
[GitHub's private vulnerability reporting](https://github.com/allthesedreams/safescreen/security/advisories/new)
when available.

Include a minimal reproduction, affected version, and expected impact. Do not
include real credentials or private desktop screenshots.

SafeScreen is a local desktop utility. It does not require administrator rights
and does not make network requests.
